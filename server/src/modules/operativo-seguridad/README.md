# Modulo Operativo / Seguridad — Dev Backend 2

Responsable: Dev Backend 2 (segun cronograma de Sprint).

Contiene:
- `auth/` — login, JWT, ruta de perfil y ruta de prueba RBAC
- `auditoria/` — servicio de registro de auditoria (`registrarAuditoria`)
- `usuarios/` — CRUD de usuarios y roles (pendiente, semana 14-sept)
- `copropietarios/` — CRUD de copropietarios e inmuebles (pendiente, semana 21-sept)

Tambien usa `src/middlewares/auth.middleware.js` y `src/middlewares/rbac.middleware.js`.
